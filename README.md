# ジグソーパズル

ブラウザで遊べるジグソーパズルです。スマホ（縦・横）とパソコンに対応しています。

**遊ぶ：** https://asobigokoro2121.github.io/jigsaw-puzzle/

## できること

- 動物・風景・世界遺産・マリンアートなど85種の絵柄（実写45枚、描き下ろしイラスト40枚）と、自分の写真
- 12〜96ピース、ピース同士の連結、ピースおき場の整列
- ピンチ／ホイールで拡大、見本の小窓、効果音、全画面
- 途中保存（このブラウザの中だけに保存されます）

## 絵柄のクレジット

イラスト40枚は、このパズルのためにコードで描いた描き下ろしです。
